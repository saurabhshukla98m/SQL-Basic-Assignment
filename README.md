# 🛒 RetailDB_1 – SQL Basic Assignment

## 📌 Project Overview
This project focuses on analyzing customer, product, and order data using MySQL.
The objective is to understand basic SQL concepts and perform data retrieval,
filtering, sorting, and aggregation on a retail database.

## 🎯 Project Objectives
- Create and manage a database using MySQL.
- Analyze customer, product, and order information.
- Retrieve specific records using SELECT queries.
- Filter data using WHERE conditions.
- Sort and limit query results.
- Perform calculations using aggregate functions.
- Understand relationships between tables.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL
- CSV Files

- Aggregate Functions

- Data Analysis Using SQL

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Create or select the `RetailDB_1` database.
4. Import the CSV files into the appropriate tables.
5. Open `LMSS.sql` in MySQL Workbench.
6. Execute the SQL queries.
7. Review the results to understand the data.

## 💡 Key Learnings
- Understanding relational databases.
- Writing and executing SQL queries.
- Retrieving and filtering data efficiently.
- Applying aggregate functions for analysis.
- Working with CSV datasets in MySQL.
